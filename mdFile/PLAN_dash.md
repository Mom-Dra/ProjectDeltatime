# Plan

## Goal
범위 추정: 현재 구현은 전역 `Time.timeScale`을 1로 유지하면서 적·투사체·투척체에 `WorldTimeController.WorldDeltaTime`을 적용하고, 플레이어 조작·UI·카메라는 의도적으로 비스케일 시간축을 사용한다. 따라서 본 계획의 “월드 시간 연동” 범위는 **월드 객체 시간축 누락 감사·보완 + 정상/감속/하드 프리즈 계약 테스트 확장**으로 한정하며, 플레이어·UI·카메라의 기존 비스케일 정책과 리플레이의 독립 시간축은 보존하고 전역 `Time.timeScale`은 임의로 변경하지 않는다.

## Tasks

- [ ] T1: 정상·감속·하드 프리즈 시간축 계약 테스트 확장
  - 변경 범위: 기존 `WorldTimeContractTests`와 필요한 최소 테스트 보조 코드를 확장해 `WorldTimeController`의 정상 배율, 감속 배율, 토큰 기반 하드 프리즈, 토큰 해제 후 복구를 독립적으로 검증한다. 테스트 준비·정리 외에는 `Time.timeScale`을 쓰지 않고, 각 구간에서 `WorldDeltaTime = unscaledDeltaTime × CurrentTimeScale` 및 전역 `Time.timeScale == 1` 계약을 명시한다.
  - 수용 기준: 정상 구간의 월드 시간이 실제 시간에 비례해 진행되고, 감속 구간은 설정 배율에 비례해 더 적게 진행되며, 하드 프리즈 중 `WorldDeltaTime`과 월드 진행량이 0이고 토큰 해제 후 다시 진행된다. 모든 검증 전후에 전역 `Time.timeScale`이 1로 유지되고 테스트가 원래 전역 상태를 안전하게 복원한다.
  - 검증 명령: `rg -n "Time\.timeScale\s*=|WorldDeltaTime|HardFreeze" ProjectDeltatime/Assets/_Project/Tests/PlayMode/WorldTimeContractTests.cs`; `"$UNITY_EDITOR" -batchmode -nographics -projectPath "$PWD/ProjectDeltatime" -runTests -testPlatform PlayMode -testFilter Deltatime.Tests.PlayMode.WorldTimeContractTests -testResults "$PWD/ProjectDeltatime/Logs/WorldTimeContractResults.xml" -logFile "$PWD/ProjectDeltatime/Logs/WorldTimeContract.log" -quit` (`$UNITY_EDITOR`에 Unity 6000.1.13f1 실행 파일 지정, Unity 에디터 확인 필요); `git diff --check -- ProjectDeltatime/Assets/_Project/Tests/PlayMode/WorldTimeContractTests.cs`
  - 관련 파일: `ProjectDeltatime/Assets/_Project/Tests/PlayMode/WorldTimeContractTests.cs`, `ProjectDeltatime/Assets/_Project/Tests/PlayMode/Deltatime.Tests.PlayMode.asmdef`, `ProjectDeltatime/Assets/_Project/Scripts/Time/WorldTimeController.cs`, `ProjectDeltatime/Assets/_Project/Scripts/Time/WorldTimeActivity.cs`

- [ ] T2: 시뮬레이션별 `WorldDeltaTime` 연동 누락 보완
  - 변경 범위: 적 이동·회전·AI 상태 타이머, 투사체 이동·수명, 투척/공중 드롭 무기 이동·회전·착지, 적 애니메이션 재생을 감사하고 월드 객체에서 확인된 누락만 `WorldTimeController.WorldDeltaTime`, `WorldElapsedTime` 또는 `CurrentTimeScale` 기반으로 보완한다. 플레이어 이동·대시·조준·공격 쿨다운, 카메라, HUD, 입력, 사용자 피드백과 리플레이 재생은 기존 비스케일 정책을 유지하며 `Time.timeScale`, `PlayerControls.inputactions`, 씬, 프리팹, ScriptableObject, Layer 8 `VisionObstacle`은 변경하지 않는다.
  - 수용 기준: 월드 시간 대상의 이동량·상태 타이머·수명·적 애니메이션은 정상/감속 배율에 비례하고 하드 프리즈에서 진행하지 않으며, 누락이 없다고 판정한 경로는 근거와 의도된 시간축이 코드 또는 테스트에서 명확하다. 플레이어 조작·UI·카메라는 하드 프리즈 처리 규칙을 제외하고 비스케일 반응성을 보존하고, 전역 `Time.timeScale` 대입이 새로 생기지 않는다. 입력 또는 시야 장애물 변경이 불가피해지면 이 작업에 섞지 않고 별도 범위로 분리해 생성 래퍼·HUD 안내·스모크 및 Layer 8 정책을 함께 검토한다.
